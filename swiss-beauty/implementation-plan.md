# Implementation Approach

## Phases
| Phase | Activity | Owner |
|---|---|---|
| 1. Discovery | Understand the order lifecycle, support process and agents' working setup | Sales Engineer + Client |
| 2. Solution design | Design the IVR flow and the handover to agents | Sales Engineer |
| 3. Message mapping | Map order status and delivery date to IVR messages | Client + Sales Engineer |
| 4. Order data access | Agree how the IVR gets order information | Client tech team + Exotel tech team |
| 5. WebRTC setup | Give agents access to browser-based calling | Exotel + Client |
| 6. Testing | Test the IVR, the handover and agent calls on laptops | Client + Exotel |
| 7. Go-live | Publish the single number on the website | Client |

## Responsibilities
**Client:** order information, support team and laptops, publishing the number on the website.
**Exotel:** number, IVR, call routing, WebRTC calling for agents.
**Sales Engineer (me):** requirements, solution design, coordination between teams.

## Agent readiness checklist
- Laptop with a supported browser
- Headset with a microphone
- Stable internet connection
- Browser permission for the microphone
